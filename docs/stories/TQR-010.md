# TQR-010: Realtime hub — SSE streams, pg_notify, resync

- Release: v0.3.0 · Status: review · Owner: Claude (deliver-loop)
- Design: ADR 0004, design.md "Integration points"; enables AC31, AC38, AC39 (built in TQR-014…016)

## Story

As a cook, waiter or guest, I want my screen to change the moment a dish changes, so that nobody refreshes or shouts across the kitchen.

## Acceptance criteria (technical, from ADR 0004)

| Id               | Given                                                      | When                                                                          | Then                                              |
| ---------------- | ---------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------- |
| R1               | a staff stream is open                                     | an event for its restaurant and topic is published in a committed transaction | the client receives a `delta` with the event data |
| R2 (negative)    | an event is published inside a transaction that rolls back | —                                                                             | no client ever sees it                            |
| R3 (isolation)   | restaurants A and B                                        | an event for A is published                                                   | B's streams never see it                          |
| R4 (failure)     | the LISTEN connection drops                                | it reconnects (backoff 0.5 → 10 s + jitter)                                   | every stream gets `resync` and a fresh `snapshot` |
| R5               | a client goes away                                         | —                                                                             | its subscription is removed (no leak)             |
| R6 (performance) | 300 open streams                                           | 50 events/s for 2 s                                                           | p95 delivery delay ≤ 2 s (spec target)            |
| R7               | no session                                                 | the floor stream is requested                                                 | 401                                               |

## Design

- `src/realtime/domain/event.ts` (codec, 7 900-byte NOTIFY cap, SSE format, backoff), `realtime.hub.ts` (one LISTEN connection per process, filtered fan-out, reconnect + resync), `publisher.ts` (`pg_notify` inside the caller's transaction), `sse.ts` (`openStream`: subscribe → snapshot → deltas, heartbeat 15 s), `stream.controller.ts` (`GET /api/stream/floor` for owner/cashier/waiter; later items add station and guest streams and real snapshots).
- Web: `src/composables/useStream.ts` (EventSource; snapshot replaces state on every (re)connect; `isNewer` for versioned deltas).
