# TQR-016: Guest live dish status

- Release: v0.3.0 · Status: review (the realtime and rush-replay benchmark rows are still open) · Owner: Claude (agent, ordering branch)
- Spec: S11 (AC38–AC39); ADR 0004; `docs/design-system.md` (one status table)

## Story

As a guest, I want to see each dish's status change by itself, so that I know what is coming without asking.

INVEST: Independent ☑ (after TQR-010, 012) Negotiable ☑ Valuable ☑ Estimable ☑ Small ☑ Testable ☑

## Acceptance criteria (spec ids)

| Id   | Given                          | When                                                                                                     | Then                                                                                                                                                                      |
| ---- | ------------------------------ | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC38 | a joined phone on "Món đã gọi" | an order is placed, held, released or rejected, or the kitchen publishes `item.status` on `session:<id>` | each dish shows Chờ xác nhận / Đang chờ / Đang nấu / Xong / Đã ra bàn / Đã huỷ (plus Chờ thanh toán) with icon + word, updated without reload; older versions are ignored |
| AC39 | the connection drops           | it comes back                                                                                            | the stream's first event is a snapshot of every order and item (< 5 s) that replaces the page state; "Mất kết nối, đang thử lại…" shows meanwhile                         |
| Auth | no or unknown cookie           | `GET /api/g/stream`                                                                                      | 401; a stream never carries another session's events                                                                                                                      |

## Design

- `GET /api/g/stream` (guest cookie → session) uses `openStream` with topic `session:<sessionId>` and the guest session view as its snapshot. Web: `useStream` in `GuestOrdering.vue`; `item.status` deltas are patched by version (`applyItemDelta`), `order.status` deltas refetch `GET /api/g/session`.
