# TQR-027: Kitchen voice announcements — new orders read aloud on `/bep`

- Release: unreleased · Status: review · Owner: Claude (deliver-loop)
- Spec: S17 (AC55–AC59), S9 (station queue, TQR-014), ADR 0004 (stream snapshot + deltas), `docs/design-system.md` ("Voice toggle (kitchen)")

## Story

As a cook, I want each new order read aloud as it reaches my station ("Bàn 1: hai phở bò, một trà đá"), so that I can keep cooking without looking up at the screen.

Owner (2026-11-08): "nhiệm vụ chính của chúng ta là order và hỗ trợ tương tác bằng giọng nói với bếp … bàn 1 đặt xuất ăn này bàn 2 đã order như thế này thì đầu bếp ko cần nhìn lên màn hình".

INVEST: Independent ☑ (after TQR-014) Negotiable ☑ Valuable ☑ (owner's top priority) Estimable ☑ Small ☑ Testable ☑ (speech is a port; tests fake `speechSynthesis`)

## Non-functional

- Offline and private: nothing leaves the device; no new dependency, no new endpoint (the queue answer gained `orderId` per ticket).
- Kitchen UI per `docs/design-system.md`: 56 px targets, 20 px text, state shown as word + icon + colour, `role="switch"` with a stable name.
- Robust: a browser that never fires `end` cannot stall the queue (guard timeout per sentence).

## Out of scope

- Voice commands (speech recognition) — candidate TQR-030 (backlog: needs Apple's servers for vi-VN on iPad, unreliable in a noisy kitchen).
- A "Tất cả khu" (all stations) view: voice covers the station tab on screen.
- Speaking on the waiter screen.

## References

- Web Speech API, `SpeechSynthesis` / `SpeechSynthesisUtterance` (MDN); Safari requires a user gesture before audio.
- WAI-ARIA switch pattern; WCAG 2.2 2.5.8 target size.

## Design

- Pure module `web/src/features/kitchen/voice/`: `phrases.ts` (number words, line/order/reminder sentences, grouping by `orderId`), `arrivals.ts` (first list primes, later lists give unseen waiting ids), `speech-queue.ts` (one sentence at a time over a `SpeechEngine` port), `browser-speech.ts` (the adapter: vi-VN, voice choice, rate/volume, guard timeout, iOS unlock), `settings.ts` (per-device `localStorage` `tqr.kitchen.voice`, every access in try/catch), `useVoiceAnnouncements.ts` (wires a station's items to sentences).
- `StationQueue` emits `say`; `KitchenPage` owns the settings and the speech queue and speaks only while on; `VoiceBar.vue` is the toggle.
- API: each ticket in `GET /api/kitchen/stations/:id/queue` (and the station stream snapshot) carries `orderId`.
