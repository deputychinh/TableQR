# TQR-024: Archive ("Ẩn bàn") a table with history

- Release: unreleased (after v0.5.0) · Status: review · Owner: Claude (follow-up of the TQR-007 R2 review)
- Spec: S3 (AC8–AC11), AC3 (isolation), AC48 (booking assignment); TQR-007 R2 review ("Archiving was not built"); `docs/design-system.md` (refused destructive action offers the safe alternative)

## Story

As a restaurant owner, I want to hide a table I no longer use even though it has served guests, so that it leaves my list, its sticker stops working and nobody can book it — while its paid bills stay in the books.

INVEST: Independent ☑ (after TQR-007, TQR-011, TQR-020) Negotiable ☑ Valuable ☑ Estimable ☑ Small ☑ Testable ☑

## Non-functional

- Concurrency: archive locks the table row and checks for an open session in the same transaction; guest check-in locks the same row through `findLiveByToken(tx, token, lock)` with `archived_at is null`, so a check-in racing an archive either wins (archive then answers 409) or sees "not found".
- Data: migration `0008_archive_tables` adds nullable `dining_tables.archived_at` (non-destructive). Names stay unique across hidden tables (`lower(name)` index), so "Hiện lại" never clashes.
- UX (owner rule): reuses `ConfirmSheet`, `StatusChip`, `BaseButton`, the toast; the hidden list is collapsed by default and says in plain words what hiding does.

## Out of scope

- Hiding from the table card directly (only from the refused-delete sheet, as asked); refusing to hide a table with a future confirmed booking (recorded as a follow-up below).

## Design

- API: `POST /api/tables/:id/archive` → 200 `TableView` (409 `TABLE_IN_USE`), `POST /api/tables/:id/unarchive` → 200; owner only; `GET /api/tables` → `{items, archived}`; `TableView.archivedAt`.
- Code: `TablesService.archive/unarchive/findLiveByToken`; `SessionsService.checkIn/checkInNext` call `findLiveByToken` (one resolver), `SessionsService.open` and `BookingService.availability/confirm` filter `archived_at is null` (read-only).
- Web: `useTables` keeps `archived` apart; `TablesPage` refused sheet → `archive`; "Bàn đã ẩn" section with "Hiện lại"; print page reads `items` only.
